# ADR-0003: Definition of done for a post

- **Status:** Open
- **Date:** 2026-08-28
- **Question:** what has to be true before a post is publishable?

## Context

The review skill (Iteration 2) has nothing to check against until this exists. It is
also the only thing that gives C2 teeth: "this dump is not enough" is unfalsifiable
without a written bar.

Asked and explicitly not answered yet — no clear idea, to be returned to. Recorded now
so the question is not lost.

## Options

Not yet framed as options. Candidate criteria, drawn from what the existing posts
actually do (see [voice.md](../voice.md)), to react to rather than to adopt:

- **The failure path is in the post**, not only the solution. Every existing post has
  it: what was tried first and why it was abandoned.
- **Exact versions named** for anything version-sensitive.
- **Sources credited** in one flat sentence where something was taken from elsewhere.
- **Open questions stated** rather than hidden. "Maybe someday I will find out" is an
  acceptable ending and appears in the corpus.
- **Redaction rules pass** (CONTEXT.md).
- **No unresolved C3 markers**, and nothing in the post that cannot be traced to the
  dump, the interrogation, or a cited source.
- **Length is whatever the problem was.** The shortest existing post is four
  sentences. Padding to look substantial is a defect, not a courtesy.

Also unframed: the bar *below* which a dump becomes a stub instead of a post, which is
the same question from the other side.

## Decision

Not yet. Needs a working session, probably easier after one real dump has been through
the pipeline and produced something concrete to argue about.
